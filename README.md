# Octave NetCDF Array Toolkit

Add access to NetCDF files as a multi-dimensional array

## Introduction

The Octave NetCDF Array toolkit provided access to collections
of NetCDF files as a multi-dimensional array

## Requirements

* Octave 4.0+

* [Octave Netcdf Toolkit](https://gnu-octave.github.io/packages/netcdf/)

* [Octave Statistcs Toolkit](https://gnu-octave.github.io/packages/statistics/)

## Installing

To install, run the octave package manager:

1. If running Windows, the package may already be installed:
   type pkg list, to view the installed packages.

2. To install from source forge/package index:

    `pkg install -forge ncarray`

3. To install from a local tarball.

    `pkg install ncarray-XXXXXXX.tar.gz`

   Where XXXXXXX is the version of the the downloaded tarball.

## Usage

1. Load the package.

   `pkg load ncarray`

   (Required each time Octave is started)

2. Use the functions
